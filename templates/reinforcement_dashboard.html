How Reinforcement Learning Works

This system uses Reinforcement Learning from Human Feedback (RLHF) to improve the feedback generation model over time:

  1. Data Collection: Instructors review and correct model-generated feedback
  2. Training Data: These corrections form training pairs that teach the model what good feedback looks like
  3. Fine-Tuning: Once enough samples are collected, the model is fine-tuned to better match instructor preferences
  4. Continuous Improvement: The process repeats, with the model getting progressively better

The dashboard shows your progress toward collecting enough data for effective fine-tuning.
